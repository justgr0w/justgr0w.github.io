Con permisos de administrador, el apartado que genera la configuración de VPN para un usuario permite inyectar código: la aplicación escribe un archivo de configuración que se procesa al conectar, y podemos meter una reverse shell en la plantilla. Escalada de Privilegios
#

Revisando el sistema encontramos una forma de escalar. Resulta ser CVE-2023-0386, una vulnerabilidad de OverlayFS en Linux:

Exploit de CVE-2023-0386

El fallo está en cómo OverlayFS fusiona archivos con permisos setuid/setgid entre las capas inferior y superior, y permite montar una imagen FUSE maliciosa que, al copiarse sobre un fichero con el bit SUID, consigue un binario SUID de root.

Clonamos el repositorio, enviamos el exploit a la máquina y ejecutamos los pasos. El resultado es un shell con privilegios de root.

git clone https://github.com/xkaneiki/CVE-2023-0386
# subir el exploit a la maquina
# ejecutarlo

Como root leemos el flag:

cat /root/root.txt

Recomendaciones de Seguridad
#

  • El PUT de usuarios debe comprobar la autorización, no solo que haya sesión. Un endpoint que cambia el is_admin de otra cuenta es una escalada de privilegios trivial, y más grave tratándose de una API de CTF donde muchos usuarios compiten.
  • La generación de configs de VPN no debe incluir entrada del usuario sin sanitizar en un fichero que se procesa. Si la plantilla admite campos, deben escaparse o validarse contra una lista blanca.
  • No almacenar credenciales en texto plano en ficheros de la aplicación. Guardar hashes y usar un gestor de secretos.
  • Parchear el kernel. CVE-2023-0386 afecta a OverlayFS en el usuario sin privilegios. Mantener el kernel actualizado es la mitigación principal: esta escalada no depende de la app, sino del sistema operativo.
  • Revisar el uso de FUSE y de OverlayFS por usuarios sin privilegios en los servidores, y restringir user namespaces con sysctl cuando no sean necesarios.
