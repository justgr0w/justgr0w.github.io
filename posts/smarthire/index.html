"""
MLFLOW-CTL: Operational interface for managing the MLflow service.
Supports a pluggable extension model for environment-specific logic.
For changes or plugin requests, please contact the Platform Team.
"""

from pathlib import Path
import sys
import site

BASE_DIR = Path(__file__).resolve().parent
PLUGINS_DIR = BASE_DIR / "plugins"

# make plugins importable
for path in PLUGINS_DIR.iterdir():
    if path.is_dir():
        site.addsitedir(str(path))

def print_usage():
    print("Usage: mlflowctl.py [status|backup-models|restart]")
    sys.exit(1)

def main():
    import mlflow_actions, backup_models

    if len(sys.argv) < 2:
        print_usage()

    action = sys.argv[1]

    if action == "status":
        mlflow_actions.check_status()
    elif action == "backup-models":
        print("[*] Running backup via backup_models plugin...")
        backup_models.run()
    elif action == "restart":
        mlflow_actions.restart()
    else:
        print(f"[!] Unknown action: {action}")
        print_usage()

Análisis a Fondo: ¿Cómo Funciona la Inyección vía site.addsitedir y Archivos .pth? Link to heading

Para comprender el vector de escalada, es fundamental analizar la arquitectura interna del módulo site de Python:

1. ¿Qué es site.addsitedir()? Link to heading

En Python, la función site.addsitedir(directory) agrega una ruta a la lista de búsqueda de módulos (sys.path). No obstante, su comportamiento va más allá de un simple sys.path.append(). Cuando addsitedir() es invocado sobre un directorio, examina de forma automática todos los archivos que finalicen con la extensión .pth (Path configuration files) presentes en esa carpeta.

2. Mecanismo de los archivos .pth (Path Configuration Files): Link to heading

Los archivos .pth fueron diseñados para que paquetes externos puedan configurar rutas de inclusión dinámicas. Su comportamiento estándar sigue dos reglas:

  • Cada línea de texto representa una ruta que debe ser incorporada a sys.path.
  • Comportamiento Crítico de Ejecución: Si una línea comienza con la sentencia import o import\t, el intérprete de Python no la interpreta como una ruta de directorio, sino que la ejecuta directamente como código Python en tiempo real (exec()).

3. Vector de Abuso en Escalada de Privilegios: Link to heading

  • mlflowctl.py se ejecuta como root a través de sudo.
  • Durante el arranque del script, itera sobre todos los directorios dentro de plugins/ y ejecuta site.addsitedir(str(path)) antes de validar o ejecutar cualquier otra función.
  • Si una de esas carpetas tiene permisos de escritura para un usuario de menor privilegio, dicho usuario puede crear un archivo .pth conteniendo una instrucción import.
  • Python procesará e interpretará esa línea con los privilegios del proceso padre (root).

Lecciones aprendidas Link to heading

  1. Gestión de Credenciales en Servicios MLOps: Las consolas administrativas como MLflow no deben conservar contraseñas predeterminadas ni exponerse sin mecanismos robustos de control de acceso.
  2. Deserialización Insegura de Modelos: Los frameworks de Machine Learning deben restringir la carga de formatos no seguros (como Python Pickle) y preferir serializaciones seguras como SafeTensors u ONNX.
  3. Peligros de site.addsitedir en Entornos Privilegiados: Cualquier script ejecutado con permisos de root (vía Sudo o SUID) que agregue directorios a sys.path mediante site.addsitedir() debe garantizar que las rutas y su contenido pertenezcan exclusivamente a root:root con permisos 755, evitando que usuarios sin privilegios puedan inyectar archivos .pth ejecutables.
