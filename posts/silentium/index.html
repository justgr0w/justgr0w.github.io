Reconocimiento Link to heading

Comenzamos verificando conectividad con la máquina objetivo:

❯ ping -c1 10.129.45.60

TTL de 63 — confirma un sistema operativo Linux. Escaneamos la totalidad de los puertos:

❯ nmap -p- --open -sS --min-rate 5000 10.129.45.60 -n -Pn -oG nmap/allPorts -v

Recomendaciones de Seguridad Link to heading

  1. Remover tokens de las respuestas de la API: El endpoint /forgot-password jamás debe retornar el tempToken en el cuerpo HTTP. El token debe ser despachado exclusivamente mediante un correo electrónico seguro.
  2. Actualizar instancias de Flowise: Actualizar Flowise a la versión 3.1.2 o posterior para mitigar inyecciones de código en customMCP.
  3. Eliminar la reutilización de credenciales: Las credenciales en archivos de entorno del contenedor (como SMTP) deben ser independientes y distintas a las claves de acceso del host principal.
  4. Parchear PackageKit / DBus: Aplicar los parches de seguridad de Ubuntu para mitigar la vulnerabilidad TOCTOU CVE-2026-41651.
